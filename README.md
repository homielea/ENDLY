# Endly (prototype)

Endly helps families prepare for difficult conversations about aging, end of life, wishes,
inheritance, and generational handover: one question at a time, with permission to pause.

**Prototype.** Use sample information. Notes are stored only in your browser. Endly gives no
legal, medical, or financial advice, and its notes are not a will or care directive.

```bash
npm install
npm run dev
npm run check   # typecheck, unit tests, build, browser tests
```
